# Fluent Python — Chapter-by-Chapter Notes & Companion Guide

Welcome! This repository contains clean, concise, and practical notes based on Luciano Ramalho's **"Fluent Python"**. 

It’s designed as an easy-to-read, quick-reference alternative to flipping through the full text—focused on core concepts, pythonic patterns, and practical code snippets.

---

## What's Inside?

* **Python Data Model:** Special methods (`__len__`, `__getitem__`, etc.), sequences, and object behavior.
* **Data Structures:** Dictionaries, sets, list comprehensions, and generator expressions.
* **Functions as Objects:** First-class functions, design patterns, and decorators.
* **Object-Oriented Idioms:** References, mutability, interfaces, operator overloading, and inheritance.
* **Control Flow:** Generators, context managers, and async/await routines.
* **Metaprogramming:** Dynamic attributes, properties, and class decorators.

---

## Purpose & Goals

1. **Quick Reference:** Quickly review core Python paradigms without reading dense prose.
2. **Code-First Learning:** Focus on executable code snippets and pythonic idioms.
3. **Structured Breakdown:** Organized chapter-by-chapter for easy navigation.

---

## How to Use

Feel free to browse through the folders/notebooks corresponding to each chapter or topic!
